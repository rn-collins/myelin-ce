# Myelin Learning Lab

Free, applied, non-credit courses, tools, and briefs for responsible AI work.

**Live:** https://myelin-ce.vercel.app

## Repository contents

`briefs.html`, `course.html`, `dashboard.js`, `free-guide.html`, `index.html`, `lab.html`, `lab.js`, `privacy.html`, `status.html`, `tools.html`, `tools.js`, `vercel.json`

## Local development

Static site. No build step — open `index.html`, or serve the directory with any static file server.

## Deployment

Deployed on Vercel from `main`. Every push to `main` triggers a production build.
